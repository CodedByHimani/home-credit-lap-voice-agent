# Home Credit LAP Eligibility Voice Agent

## Project Overview
This project involves developing an AI-powered voice agent for Home Credit to conduct preliminary eligibility checks for a Loan Against Property (LAP). The agent communicates with customers, collects the required information, checks eligibility criteria, and provides the appropriate next steps.

## Objectives
- Automate preliminary Loan Against Property eligibility checks.
- Collect customer details through a natural voice conversation.
- Identify eligible and ineligible applicants based on predefined criteria.
- Refer existing-loan transfer or lower-EMI requests to a specialist.

## Technology Used
- **Bolna AI:** Voice agent creation and conversation management.
- **AI System Prompt:** Defines the agent's role, instructions, eligibility rules, and conversation flow.
- **Voice Recording and Transcript:** Used to review and demonstrate the agent's conversations.

## Eligibility Parameters
The agent checks:
1. Property type
2. Property ownership
3. Availability of original property documents
4. Requested loan amount (maximum ₹75 lakh)
5. Occupation and income received through a bank
6. Current market value of the property
7. Requested loan tenure (3–15 years
